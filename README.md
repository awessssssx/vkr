## Файлы
- `1_data.py` — загрузка и объединение данных (INNER по индексу), проверка пропусков, среднее и медиана
- `2_graphics.py` — гистограммы, диаграммы «ящик с усами», попарные графики рассеяния, корреляции
- `3_preprocessing.py` — исключение выбросов, нормализация, графики до и после
- `4_models.py` — модели для модуля упругости и прочности
- `5_keras.py` — нейронная сеть для соотношения матрица-наполнитель
- `app.py` — приложение с графическим интерфейсом
- `model_nn.keras`, `scaler.pkl`, `features.pkl` — сохранённая модель, нормализатор и порядок признаков
- `feature_stats.csv` — средние значения признаков, подставляются в поля приложения по умолчанию
- `output/` — графики и таблицы

## Установка и пошаговый запуск
```
pip install -r requirements.txt
python 1_data.py
python 2_graphics.py
python 3_preprocessing.py
python 4_models.py
python 5_keras.py
streamlit run app.py
```
